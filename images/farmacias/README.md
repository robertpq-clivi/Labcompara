# Logos de farmacias

Sube aquí los logos para la sección "Los mejores tratamientos GLP-1" de la home.

Nombres de archivo EXACTOS (en minúsculas). Puede ser .png (recomendado, con
fondo transparente) o .svg — si usas .svg cambia la extensión en LOGOS dentro de index.html.

- clivi.png
- revert.png
- ahorro.png          (Farmacias del Ahorro)
- guadalajara.png     (Farmacias Guadalajara)
- benavides.png
- sanpablo.png        (San Pablo)

Recomendación: imágenes cuadradas, ~200×200 px, fondo transparente.
Si falta algún archivo, la tarjeta muestra el emoji como respaldo automáticamente.
